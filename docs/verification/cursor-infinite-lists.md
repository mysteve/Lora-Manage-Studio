# 模型与图像游标追加列表

## 实现

- 我的模型新增 `list_library_page`，每批最多60条，筛选后按排序键及唯一ID做keyset分页，游标绑定条件并校验版本和长度。名称采用大小写敏感Unicode字典序，最新及大小降序，同值ID升序。
- 保留全量library供统计及关联查询。模型后端仍读取JSON记录后筛选排序，图像后端仍扫描目录；此次没有实现数据库索引分页或增量文件扫描。
- 我的图像复用现有游标接口，累计已加载批次，移除列表页码按钮；保留查看器跨批切图和有限预解码。
- 两个列表使用IntersectionObserver接近底部追加，保留手动加载、失败重试和到底提示；回顶按钮固定右下，超过400px显示，详情及看图时隐藏，减少动态效果时立即回顶。
- 原有未提交的详情精简与触发词样式改动保留，未提交或推送代码。
