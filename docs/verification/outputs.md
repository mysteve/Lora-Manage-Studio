# ComfyUI 输出结果目录

日期：2026-09-10。

侧栏新增输出结果页面，默认读取绑定根目录下的 `output`。工作空间设置的 `outputDir` 留空时跟随绑定目录，也可填写或选择已有文件夹，恢复默认后保存即可重新跟随。该配置仅指定查看位置，不修改 ComfyUI 的启动参数或保存节点。

递归读取 PNG、JPG、JPEG、WebP，按修改时间倒序排列，每页 60 张，支持刷新、放大预览、打开目录及定位图片。不存在的默认目录显示空状态，不自动创建目录。自定义目录保存时要求绝对路径且已存在。扫描不跟随符号链接，仅为返回的图片逐个授权本地资源访问。

## 图片生成信息补充

点击图片后，在详情中读取并显示模型与 LoRA 权重、正负提示词、随机种子、步数、CFG、采样器、调度器和降噪强度，支持复制单项、复制整组和查看原始记录。宽窗口采用图片与参数双栏，窄窗口上下排列。

支持 PNG 的 tEXt、zTXt、iTXt（包含图像数据之后的文本），以及 JPEG/WebP 中 ComfyUI EXIF 文本和常见 UserComment。实现依据包括 [ComfyUI SaveImage](https://github.com/Comfy-Org/ComfyUI/blob/master/nodes.py) 和 [图片保存节点](https://github.com/Comfy-Org/ComfyUI/blob/master/comfy_extras/nodes_images.py)。PNG 解析直接使用锁定文件已有版本的 png 库。

前端按工作流连接整理 KSampler、KSamplerAdvanced、SamplerCustom 和 SamplerCustomAdvanced。忽略未连接到已识别保存节点的采样分支；存在多个输出时，图片记录可能包含全部分支，界面分别列出，不能据此唯一确定当前图片所属分支。未知自定义节点保留原始记录，不执行工作流或猜测缺失提示词。仅保存工作流布局而没有执行记录时，显示原始记录。无内嵌信息的图片显示缺失说明。

补充验证：生产构建通过，31 项前端测试通过；Rust 全量测试 55 项通过、1 项联网测试忽略，之后新增 JPEG/WebP 容器往返测试，4 项元数据专项测试通过。Clippy 通过。测试覆盖连接关系、无关分支、多次采样、64 位种子、零值、未知和循环节点、PNG 压缩文本、IDAT 后文本、EXIF 偏移校验、文件损坏、信息缺失和输出目录边界。

浏览器预览检查了 1440×900 双栏与 1000×800 单栏，参数复制提示、Escape 关闭、完整种子及无横向溢出。截图为 `output-metadata-1440.png`、`output-metadata-1000.png`。生成记录使用明确标记的开发样例，与占位图片本身无关；`metadata-preview=empty` 和 `metadata-preview=error` 可分别检查缺失及读取失败状态。

真实桌面命令至 WebView 的完整联调尚未执行，未测试所有第三方保存节点或 EXIF 私有格式。

## 与现有 LoRA 库关联

从每组生成记录提取 LoRA 文件名，优先按绑定 LoRA 目录下的相对路径或记录中的绝对路径匹配库记录；其次按文件名匹配。parameters 文本中的 `<lora:name:weight>` 支持省略扩展名。Windows 路径大小写和分隔符统一处理，不使用用户编辑的模型展示名称做匹配。

图片详情显示关联模型的封面、名称、基础模型、版本、路径和缺失状态。无法按路径区分的同名文件全部列为候选，不保存自动匹配关系。文件名匹配不代表文件内容或历史版本完全一致，界面提示核对版本。没有可识别 LoRA 文件名的自定义节点仍需查看原始记录。

打开关联模型复用现有模型详情；返回输出图片会恢复原图和页码，切换主导航时关闭原图，更换输出目录时重置视图。

本轮构建与 36 项前端测试通过，覆盖路径优先级、绝对路径、多候选、缺失文件、无扩展名及不按展示名称误匹配。浏览器预览核对了 1440×900 和 1000×800 关联卡片，以及进入已有模型详情后返回原图。截图：`output-lora-link-1440.png`、`output-lora-link-1000.png`。本轮未改动 Rust，无新增真实桌面联调结果。
