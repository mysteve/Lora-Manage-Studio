# 编辑保护、导航与异常恢复改进

## 范围

- 配方保存响应保留提交后的编辑，切换配方后忽略旧保存结果。
- 设置页汇总各标签及未保存密钥的修改状态，接入离开和应用关闭确认。
- 当前提示词组合独立自动保存与恢复，读取失败禁止覆盖，写入失败明确提示。
- 详情和链接解析请求失效保护，搜索条件快照与同页重试。
- 下载失败通知去重、失败计数与筛选、空列表提示、进度条可访问名称。
- 加入队列不强制离开详情，提供查看下载操作。
- AI 配置读取失败原地重试。
- Tab 只接受主动选择的候选；看图支持 Shift + 方向键平移、+ / = / - 缩放、0 复位。
