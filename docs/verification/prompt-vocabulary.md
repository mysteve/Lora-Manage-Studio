# 提示词补全与词库验收

日期：2026-09-11。环境：Windows，Vite 开发预览 `http://127.0.0.1:1420/?preview`，使用示例数据及独立 preview 词库。

## 实现

- 内置 81 条文生图词句及中文翻译，覆盖画质、风格、人物、构图、光影、场景、色彩、句式和负向提示词。
- 支持英文前缀、词中/末尾片段、中文翻译、别名和多关键词匹配；正负向按适用范围筛选，停用词条不参与补全。
- 从光标向前识别当前词句，鼠标或 Enter/Tab 插入英文，上下方向键选择，Esc 关闭，Shift+Enter 换行。权重和相邻词句保留，LoRA 表达式内部不触发。
- 编辑区底部提供词库管理，支持分类筛选、新增、编辑、启停、确认删除；重复英文词句禁止保存。
- 版本化 localStorage 保存词库；preview 键与桌面键隔离，读取失败时使用内置候选且禁止覆盖原数据。
