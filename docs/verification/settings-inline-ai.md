# 内嵌设置与 AI 接入验收

日期：2026-09-09。

## 本次变更

设置作为主内容区页面展示，保留侧栏和面包屑，首次配置也进入此页面。常规设置保存后留在页面，首次跳过返回模型列表。

AI 接入默认选择 DeepSeek。第三方服务须兼容 OpenAI 模型列表格式，基础地址可包含 /v1。获取模型后可选择或手动输入模型 ID，AI 配置单独保存。模型列表请求遵循已保存的代理配置，30 秒超时，不跟随重定向。尚未执行任何翻译请求。

配置保存在 SQLite settings 表的 ai 记录，与旧设置兼容。密钥按规范化的 API 地址存入 Windows 凭据管理器，前端只读取是否已保存，不回传原密钥。服务错误不直接展示响应正文。

接口依据：[DeepSeek 模型列表文档](https://api-docs.deepseek.com/api/list-models)。

## 后续调整：分类标签页

设置拆分为工作空间、网站访问、AI 接入三个标签页，各有独立保存按钮；本地存储信息归入工作空间。密钥仍使用原有的安全保存按钮。标签切换保留输入，支持左右方向键、Home、End，隐藏面板不参与键盘焦点导航。

本次前端构建及 14 项测试通过，新增 3 项测试覆盖分类保存隔离和其他分类草稿保留。浏览器验证：修改工作空间目录但不保存，保存网站设置后，工作空间草稿仍保留；离开设置再进入，目录恢复原来已保存的值，确认未被网站保存操作提交。1000px 和 1440px 页面无横向溢出，正常模式刷新后控制台无错误或警告。截图见 settings-tabs-ai-1000.png 和 settings-tabs-workspace-1440.png。本次未修改 Rust 接口，未重复桌面真实凭据联调。
