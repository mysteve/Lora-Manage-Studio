## 历史验收

在线发现此前只显示当前页数，返回上一页会截断后续游标。现在独立保存当前页与已知游标列表，显示可点击数字页码，保留已经获取的后续页面；网站返回的下一页游标立即成为新的页码入口。页码过多时显示首尾、当前页附近页码及省略号。重新搜索和更改筛选仍建立新的分页记录；网站游标发生变化或结束时删除失效的后续记录。

当前后端使用游标协议，没有提供可直接跳到任意远处页码的接口；本次没有猜测总页数或构造不存在的游标。

本次验证：

- `npm run build`、`npm test`（61 项）及 `git diff --check` 通过。构建仍有主 JS 分块超过 500kB 的提示。
- 内置浏览器打开 `http://127.0.0.1:1420/?preview&pagination-preview`。开发预览模拟 12 页游标，模型卡片复用示例数据，不代表真实网站内容。
- 点击第 2 页显示 1、2、3；进入第 3 页后返回第 1 页仍显示 1、2、3、4；可直接点击第 4 页，aria-current 正确。控制台无 warning/error。
- 单元测试覆盖后续游标保留、变化、末页、重复游标及多页省略规则。
