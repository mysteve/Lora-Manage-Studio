## 后续改进：缩放、分页预取、原始 prompt 解析

- 点击图片放大两倍，放大后拖动查看，再次点击还原；切换图片重置缩放并保留看图按钮焦点。移除底部快捷键文字。
- 在当前页前后五张附近预取相邻页，并预加载跨页目标图片；请求合并、缓存仅保留相邻页，刷新或切换目录时重建缓存。跨页等待不移除当前图片，失败提示后可再次点击重试。
- 原始 `text.prompt` JSON 可作为解析来源，兼容字符串及 prompt 封装，并保护大整数。沿 CLIPTextEncode 的文本连接读取 ImpactWildcardProcessor 的 reproduce 模式 populated_text；补齐 Seed (rgthree) 与 easy int 等值节点。测试采用相同连接结构的风景文本，不保存用户的完整提示词。

本次验证使用 `?preview&outputs-preview&metadata-preview=wildcard&outputs-delay`：

- 模拟第二页读取延迟 1.5 秒，第 60 张画面及序号保持显示，完成后切至 61/65，未出现替换整张图片的加载提示。
- 点击放大、鼠标拖动后变换为 `translate(90px, 120px) scale(2)`，再次点击缩小。
- 正负提示词分别显示 mountain, morning light 和 blurry, watermark，种子显示 812642747445401，步数显示 30。
- 完整刷新复查：放大后按右方向键切图，缩放复位，焦点仍在看图按钮，Tab 移到上一张按钮；控制台没有 warning 或 error。
- 本次 `npm run build`、`npm test`（55 项）和 `git diff --check` 通过；分页缓存测试覆盖请求合并、失败重试和旧页释放，提示词测试覆盖样例连接结构、无效 JSON、未确定的通配符模式及 64 位整数精度。

未实测真实大目录的扫描耗时、磁盘图片解码延迟和本次运行期间的系统减少动态效果切换；不能将预览延迟测试视为真实磁盘性能指标。

## 后续改进：悬停背景和滚轮

- 覆盖公共按钮悬停背景，避免图片两侧空白区域变亮，同时移除看图按钮按压时的位移。
- 未放大时向下滚动切下一张、向上切上一张，累计小幅滚动并以 280ms 限速；放大后以鼠标位置为中心缩放，范围为适应窗口的 1–8 倍。滚轮缩回 1 倍后抑制 450ms 切图，减少惯性误触。
- 本次浏览器示例数据实测：滚轮由第 1 张切到第 2 张；点击放大后滚轮由 2 倍放至约 2.67 倍，仍保持第 2 张；悬停背景计算值为透明；参数面板滚动至 360px 时图片及缩放不变。控制台无 warning/error。
