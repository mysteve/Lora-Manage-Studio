## 性能与数据兼容

- 进入词句组合时动态导入独立词库分包，离线使用；不增加 CSP 网络权限，不向外部服务器查询标签。
- 搜索字段和中文翻译索引按词库数组缓存，词库修改后重建。补全最多返回 8 条，管理页面每页只渲染 50 条，长别名最多显示两行，完整内容可通过悬停或编辑查看。
- localStorage 使用相同键、version 2 差异结构，只保存个人新增、修改和删除记录。
- version 1 全量快照兼容读取：保留旧条目的编辑、停用、删除及自定义条目，同时加入扩展词库；成功保存时写入新版，旧数据读取失败禁止覆盖。
- 自动测试验证针对完整词库的一次编辑及删除，保存内容少于 1,000 字符，没有把 23 万条词库写入 localStorage。
