# 输出结果滚轮响应优化

2026-09-10，Windows，浏览器开发预览。

代码排查发现原有滚轮限速为 280ms，间隔内事件被丢弃；同页相邻原图没有预解码，跨页仅预取首张地址；每次选择图片会重新构造整页卡片。

本次将同向间隔调整为 50ms，反向达到阈值即可响应，不积压事件或延迟补跳。保留小幅滚动累积，以及缩放模式和缩回适应窗口后的保护期。提前异步解码同页前后两张及跨页边界图片，缓存最多保留六张引用，失败可重试，关闭、刷新或更换目录时释放。卡片节点按列表数据记忆，选择图片时复用。

验证：`npm test` 19 个文件、63 个测试通过；`npm run build` 通过，仍有大分块提示；`git diff --check` 通过。新增测试覆盖响应间隔、快速反向、解码缓存上限、释放和失败重试。

浏览器 `http://127.0.0.1:1420/?preview&outputs-preview` 全新加载后，滚轮向下从第 59 张到 60、61 张，向上从 61 返回 60，控制台无 error。未测量真实文件解码帧耗时，未验证真实 WebView2、超大图片、参数面板开启时的性能、不同窗口尺寸及动态效果偏好切换；本次不宣称已消除全部桌面卡顿。

后续按用户要求将同方向间隔定为 50ms，边界测试覆盖 49ms 不切换、50ms 切换，以及反向后的独立限速；重新运行前端测试与构建。上述浏览器交互记录来自调整前的 140ms 版本，50ms 版本尚未重新做浏览器或真实桌面流畅度验收。
