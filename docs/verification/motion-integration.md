# 动效接入验收

日期：2026-09-09。

## 接入范围

- Motion：主导航选中背景、页面与详情进退、所有现有弹窗及提示条的进入和退出。
- Morphicons：下载任务暂停、继续、重试，API 密钥显示与隐藏，提示条状态图标。下载控制按钮保持同一个组件实例，使图标可以连续形变。
- React Bits：按源码引入 CountUp，用于模型数量；原始许可与来源说明位于 `src/components/react-bits/`。
- CSS：首批模型和配方卡片短距离错峰入场，收藏反馈、设置和返回图标悬停反馈。
- 系统减少动态效果设置：CSS 与 JavaScript 同时响应，包括应用打开期间改变偏好。

## 验证

- `npm run build` 通过；产物主 JavaScript 为 446.45 kB，gzip 为 141.08 kB。这是整个应用的产物大小。
- `npm test`：2 个测试文件、7 项现有测试通过。
- `git diff --check` 通过。
- 浏览器预览连续快速切换六次：最终只有一份页面和一个导航选中背景，页面不处于 inert 状态。
- 模型详情进入与返回正常。
- 设置和密钥帮助两层弹窗：Escape 逐层关闭，焦点分别回到帮助按钮和设置按钮。
- 1000px 与 1440px 宽度：无横向溢出。
- 动态启用减少动态效果后，页面 opacity 为 1、transform 为 none，卡片 animation 为 none，数量直接显示最终值。
- 临时浏览器组件验证：暂停切换继续时 SVG 节点保持同一个实例，图标路径存在不同于起点和终点的中间状态。
- 最终版本完整刷新后复查控制台。开发过程更换 Hook 时发生过热更新提示，最终检查使用完整刷新排除旧模块状态。

浏览器测试使用 `?preview` 的示例数据；未执行真实下载、保存凭据或构建 Windows 安装包。
