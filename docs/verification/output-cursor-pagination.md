# 输出结果游标分页

日期：2026-09-10，Windows。本次修改覆盖输出列表、看图跨页、缓存及开发预览。

## 行为

- `list_output_images` 参数改为可空 `cursor`，返回 `nextCursor` 和本次扫描的 `startIndex`。保留真实总数用于图片数量和看图位置，不以总数计算下一页。
- 游标包含版本、规范化目录、修改时间和相对文件名，沿原有修改时间降序、文件名升序读取后续最多 60 张。新增靠前图片或删除边界图片不会造成页偏移。跨目录或损坏游标报错并允许刷新。
- 前端保存历史游标，界面只显示上一页、当前页、下一页。前后跨页根据实际列表长度和下一游标判断，上一页取实际末张，不假设每页都有 60 张。
- 保留相邻页预取、并发请求复用、切图时保留当前图片和返回详情的位置记录。刷新、修改目录时重置游标和缓存。
- 仍会递归扫描并排序目录，游标本身不消除扫描成本；不是冻结快照，图片被改名或重新写入仍可能改变顺序。缓存内容通过刷新更新。
- 继续使用原有目录校验，不跟随符号链接；仅将返回图片加入本地资源协议许可。
