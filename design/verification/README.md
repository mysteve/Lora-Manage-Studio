# 验收记录

验收日期：2026-09-08；Windows x64，真实 Tauri + WebView2 桌面窗口。

## 已通过

- 17 个 Rust 自动化测试：链接解析、HTML 清理、内容图片过滤、API 错误分类、SHA-256、文件名安全、原子安装不覆盖、无效文件、断流、Range 续传/被忽略、写入失败、SQLite 持久化及中断任务恢复。
- 3 个前端测试：提示词组合、名称/标签/触发词搜索、未匹配模型的配方隔离。
- TypeScript/Vite 正式构建、Clippy 全目标零警告检查、NSIS 安装包生成及安装后的程序启动。
- 在真实桌面版通过 Rust 下载公开模型 79430 / 84238 / 57575，文件大小 9,549,232 字节，独立 Get-FileHash 结果与网站 SHA-256 一致。
- 第二个真实模型 45218 / 49832 / 36633 在 6,160,384 字节时暂停，关闭并重启应用后继续，完成 37,863,122 字节下载并校验入库。
- 中文文件名历史模型通过哈希补齐资料，未匹配文件保留在库中。
- 个人名称、标签、收藏、备注、自定义封面和提示词配方经过网站资料刷新及应用重启后保留。
- 1600 × 1000、1280 × 800 页面检查；以 1280 × 800 / 1.25 DPR、1067 × 667 / 1.5 DPR 模拟缩放后的有效视口，未发现横向溢出。没有修改用户的 Windows 显示设置。
- 主模型库 axe 检查无确定的违规项；渐变背景上的对比度由截图人工复核。

`01-library-*`、`02-detail-*`、`03-discover-*`、`04-downloads-*` 是实际前端组件截图。画面明确标注为设计验收预览，使用网站模型资料和模拟安装状态检查布局；这些预览状态不会进入正式构建。

`05-real-download.png` 是真实桌面环境下载完成后的截图。`functional-results.json` 保存真实模型编号、字节数、哈希和恢复结果。

布局沿用效果图的深色侧栏、浅绿色强调色、封面网格、双栏详情与队列列表；导航标签统一采用主图中的产品范围。实际模型标题和图片以网站资料为准。

后续按用户反馈移除了 Windows 原生标题栏，将窗口按钮融入界面右上角，Logo 与面包屑区域承担窗口拖动和双击最大化。旧版截图保留了调整前的窗口外框。

## 尚未验证的外部条件

按照用户后续要求，ComfyUI 运行检测与“待检测”状态已移除。当前只绑定根目录并将文件放入 `models/loras`，无需运行 ComfyUI。历史截图中的连接状态属于旧版行为。

根目录绑定新增 3 个 Rust 测试，覆盖中文便携版目录、自动创建模型目录、错误路径不创建目录，以及旧版设置兼容。当前 Rust 共 20 个测试通过；前端类型检查与正式构建通过。

没有使用用户账号 Token 测试受限模型；公开模型联调已完成。权限失败与限流的错误分类有自动化测试。

测试目录为项目内 `.test-data`，与正式用户数据分开。正式程序安装在项目 `app` 目录，首次使用需要在设置中绑定实际 ComfyUI 根目录。
